lynxde

A desktop environment built on its own compositor. Fast, hackable, yours.

GitHub Install

What it does

■

Own compositor

LWP handles tiling, input, and rendering. No Wayland required.

▶

Pure Python

Every component is Python + PySide6. Readable, no C extensions.

↻

Live settings

Change theme, gaps, blur, wallpaper — applies instantly.

⌘

Command palette

SUPER + / searches apps, packages, and the web.

⚙

Built-in store

Install and remove pacman packages from the desktop.

◉

5 color themes

Lynx, Amber, Forest, Ocean, Rose. Custom accents too.

⏱

Desktop widgets

Clock and OpenStreetMap tiles on the background layer.

↑

Auto updates

Checks GitHub daily. Update from settings or run lynx-update.

Getting started

Pick Lynxde from your display manager

SDDM, GDM, LightDM — just select it and log in.

Open the command palette

Hit SUPER + / to search everything at once.

Customize it

SUPER + O opens settings. Everything applies live.

Install apps

Type a package name in the palette or open lynx-store.

SUPER + / Command palette
SUPER + O Settings
SUPER + X Close window

Install

pacman

# add the repository
sudo pacman -S wget
wget -qO /tmp/lynx-de.pkg.tar.zst https://eotter-beep.github.io/lynxDE/x86_64/lynx-de-0.1.0-1-x86_64.pkg.tar.zst
sudo pacman -U /tmp/lynx-de.pkg.tar.zst

# or add to /etc/pacman.conf
# [lynx-de]
# Server = https://eotter-beep.github.io/lynxDE/x86_64

sudo pacman -S lynx-de

manual

git clone https://github.com/eotter-beep/lynxDE.git
cd lynxDE
./install.sh
